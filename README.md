# Housing Price Prediction Model

Модель машинного обучения для прогнозирования стоимости квартир в Москве на основе открытого датасета с использованием библиотеки Scikit-Learn.
Проект реализован по классическому пайплайну машинного обучения, описанному в книге Орельена Жерона «Прикладное машинное обучение с помощью Scikit-Learn и TensorFlow».

# Цель проекта

Разработать модель машинного обучения, способную прогнозировать стоимость квартиры по её характеристикам.

Проект выполняет:

- загрузку и исследование данных
- анализ структуры датасета
- предварительную обработку признаков
- построение пайплайна
- обучение нескольких моделей регрессии
- сравнение качества моделей
- кросс-валидацию
- подбор гиперпараметров с помощью GridSearchCV
- сохранение лучшей модели


# Используемые технологии

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Joblib


# Используемый датасет

Использован открытый датасет с данными о стоимости квартир в г.Москва и Московской области по состоянию на 2023 год.
https://www.kaggle.com/datasets/egorkainov/moscow-housing-price-dataset

Датасет содержит:

- тип квартиры
- станция метро
- время до метро
- район
- количество комнат
- общая площадь
- жилая площадь
- площадь кухни
- этаж
- этажность дома
- тип ремонта
- стоимость квартиры


# Этапы проекта

1. Исследование данных

Перед обучением модели были выполнены:

- просмотр структуры датасета
- анализ типов данных
- поиск пропусков
- получение описательной статистики
- визуализация распределения признаков


2. Обучение моделей

Были реализованы и сравнены три алгоритма регрессии:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

После обучения каждая модель оценивалась на тестовой выборке.


3. Оценка качества

Для оценки использовалась метрика RMSE

Дополнительно была выполнена перекрестная проверка (Cross Validation)


4. Подбор гиперпараметров

Для лучшей модели был выполнен автоматический подбор гиперпараметров с помощью GridSearchCV.

5. Сохранение модели

После завершения обучения лучшая модель сохраняется в файл model/best_model.pkl с помощью библиотеки Joblib.


# Результат

В результате проекта была построена модель машинного обучения, позволяющая прогнозировать стоимость квартир в Москве на основе их характеристик.
